# Brilliant Benius

![Brilliant Benius](concept-03.svg)

Pick the right AI tool for the right task, like a genius. Use Brilliant Benius.

A free-first, rules-based guide to choosing a tool sequence. Start with a landing-page workflow, or explore research, campaigns, spreadsheets and presentations.

## What works
- Task, input-sensitivity and device choices.
- A suggested sequence, starter prompt and quality checklist.
- Official provider source links with last-checked dates.
- Downloadable workflow notes.
- A synthetic landing page with a complete worked recipe.
- Phone-friendly layout and optional animation that respects reduced motion.

## Try it locally
Download the repository and open index.html in a browser. No install, account or API key is needed for this guide. Any AI service you choose to use separately has its own terms, limits and eligibility requirements.

## What it does not do
This is not an AI runner or benchmark. It does not call models, collect keys, automatically publish content, or promise the best output. The worked landing page is manually authored and browser-tested, not a measured provider comparison. The other tasks are starter workflows.

## Privacy
No telemetry, persistent storage or task uploads. External source links leave this guide. Do not paste sensitive information into a free cloud service without checking its terms. The guide warns when a private phone-only route has not been verified.

## Sources and freshness
Provider notes checked 2 October 2026. Free tiers and policies can change. Check the official linked pages before use. Gemini free-tier content may improve Google products. GitHub Models is excluded because its official documentation says it retired on 30 July 2026.

## Tests
Run node test.js. Browser tests cover routing, reset, exports, mobile overflow and reduced motion. Native link focus and anchor activation were browser-tested; physical Tab/Enter key navigation has not yet been independently verified. A live AI Studio check stopped at an upgrade/API-key requirement; no provider run was performed.

## Contribute
Useful contributions: a sourced correction to a provider note, a complete reproducible workflow example, accessibility fixes or reviewed translations. Cite official sources and the date checked. Use synthetic data. No promotional link dumps, fake benchmarks or API keys.
