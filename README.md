# Brilliant Benius

![Brilliant Benius](brilliant-benius-logo.svg)

Pick the right AI tool for the right task, like a genius. Use Brilliant Benius.

A rules-based guide to choosing a tool sequence with free and paid options. Start with a landing-page workflow, or explore research, campaigns, spreadsheets and presentations.

## What works
- A typed-needs box with local English keyword matching across five task categories. Mixed and unknown needs ask you to select a task.
- Dated free and paid plan options with official source links and limits.
- Task, input-sensitivity and device choices.
- A suggested sequence, starter prompt and quality checklist.
- Official provider source links with last-checked dates.
- Downloadable workflow notes.
- A synthetic landing page with a complete worked recipe.
- Phone-friendly layout and optional animation that respects reduced motion.

## Try it locally
Download the repository and open index.html in a browser. No install, account or API key is needed for this guide. Any AI service you choose to use separately has its own terms, limits and eligibility requirements.

## What it does not do
This is not an AI runner or benchmark. It does not call models, collect keys, automatically publish content, or promise the best output. The worked landing page is manually authored and browser-tested, not a measured provider comparison. The other tasks are starter workflows.

## Privacy
The app sends no typed needs to a server or model, uses no app telemetry and stores no task input persistently. Text stays in page memory until reset or reload. GitHub Pages may log visitor IPs for security. External source links leave this guide. Do not paste sensitive information into a free cloud service without checking its terms. Paid does not mean private. Use redacted examples or a verified local-only workflow.

## Sources and freshness
Provider notes checked 2 October 2026. Free and paid tiers, pricing and policies can change. ## Tests
Run node test.js. Browser tests cover routing, reset, exports, mobile overflow and reduced motion. Live Tab/Enter activation of the synthetic sample CTA was tested. Need matching tests cover blank, unknown, mixed and script-like input. A live AI Studio check stopped at an upgrade/API-key requirement; no provider run was performed.
